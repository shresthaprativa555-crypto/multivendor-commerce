# Multi-Vendor E-Commerce System

## Project Overview

The Multi-Vendor E-Commerce System is an online shopping platform that allows multiple vendors to sell products through a single website.

## Main Features

* Product catalog and product search
* Vendor registration and management
* Shopping cart and checkout
* Online payment gateway integration
* Order management
* Inventory and stock tracking
* Admin dashboard

## Technology Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js
* Database: MySQL
* Version Control: Git and GitHub
* Project Management: ProjectLibre
* Team Communication: Slack

## Branching Strategy

* `main`: Stable production-ready code
* `dev`: Integration and testing
* `feature/*`: Individual feature development

## Team Workflow

Developers create feature branches, commit their changes, open pull requests to `dev`, request code reviews, and merge only after approval and successful testing.
